\title{StepCheck: a deterministic context firewall and gated state engine for AI coding agents}
\begin{document}
\maketitle
\begin{abstract}
Long agent sessions degrade in two coupled ways: the context re-read every turn grows until attention over it decays, and silent omissions pass the tests the agent still runs. StepCheck interposes a deterministic kernel between agent and model: modules are compiled into OKF frames, checked out as AST skeletons with a chosen focus, and modified only through patches that must pass three gates before a DSSE attestation lands. We evaluate on 9 installed packages (387 files, 152,176 LOC) and on the kernel's own repository; the 50-turn benchmark sends 14,048 tokens where a raw agent sends 120,815 (88.4\% saved).
\end{abstract}
