How this was computed

Pure arithmetic over the transcript, no model calls. A turn is a cache-gap turn when its timestamp is more than 300 s after the previous assistant turn; its cache_creation_input_tokens is the prefix that had to be re-written. Skeleton tokens are the real focus=[] AST skeleton of each Read result where it parses as Python (otherwise a flat 25% estimate, flagged). A regression is an Edit whose old_string had a decorator or if …: raise that new_string lacks; retries are later edits to the same file within 5 turns. Gate B catches the first kind, an auto-mined Gate C invariant the second.
