What the upgrade pass changed

Caveat (v1)Resolution
Gate C invariants were string containment over raw source — brittle to whitespace, blind to semantics. Invariants now evaluate against src = ast.unparse(tree) (normalized, comment-free, self-reference-proof), tree (the ast.Module) and ns (the staged module exec-loaded into an isolated namespace with project imports resolved to canonical sources). Sugar: call:charge("acct", 0) raises ValueError. Legacy string invariants are unchanged and now whitespace-proof.
Compacted tokens reached 73k (45.3%): every commit re-sent the whole module and every checkout dragged the full verified[] chain plus data ballast. Checkout takes focus=[…]: focused defs verbatim, the rest of the target as an AST skeleton (signatures, decorators, docstrings, assignment runs folded to one line); dependencies ship as interface skeletons. Commits take a patch of AST ops (append / replace_symbol / delete_symbol) folded into canonical state, and telemetry charges the patch, not the module. Superseded attestations fold into one summary in the payload (the on-disk frame keeps the full chain).

Kernel caveats closed in the hardening pass

Caveat (v2)Resolution
An unfocused checkout(focus=None) carried whole-module source and could breach the <4,000-token budget on large files. When the unfocused frame would meet the budget, checkout() falls back to a pure AST skeleton with a symbol index and sets auto_skeletonized=True; the frame tells the agent to re-checkout with focus=[…]. Small modules are untouched.
Callable invariants executed staged code with no bound — a runaway loop or recursion at Gate C could hang the kernel. Namespace loading and every invariant evaluation run under a per-thread trace guard (_sandbox.guarded): 200,000 line-event step budget, 0.5 s wall-clock backstop. Overrun is a deterministic LogicalError naming the invariant; RecursionError simply fails the invariant. The kernel stays healthy and the next correct diff passes.

Packaging

One port now serves everything: stepcheck up mounts the compiled Studio at /studio (SPA deep links fall back to index.html, missing hashed assets still 404) beside Door 1, /v1/step/*, Streamable HTTP MCP at /mcp and WS /v1/ws/*. stepcheck benchmark, stepcheck review and stepcheck preview regenerate the numbers, this report and the self-contained stepcheck-studio-preview.html replay.

Risks worth watching

The execution guard bounds time, not capability: callable invariants still run the agent's staged code in-process with real imports, so run the kernel in a container when agents are untrusted. The WS fan-out is in-process; multi-worker deployment needs a shared bus.
